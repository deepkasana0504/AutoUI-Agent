## Current Status

This is an **early prototype**.

The current focus is on building the basic computer-control layer and understanding how an AI assistant can reliably interact with a graphical interface through MCP.

Future work includes improving:

- OCR reliability
- UI element localization
- Action verification
- Handling dynamic interfaces
- Multi-step task execution
- Safety around consequential actions
- Support for more computer interactions

## Why I Built It

I wanted to explore how MCP can be used beyond traditional API integrations — specifically, as a bridge between an AI assistant and the graphical interface of a real computer.

The project is still evolving, but the current prototype provides the foundation for experimenting with AI-driven computer interaction.
